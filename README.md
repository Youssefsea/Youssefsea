## 👨‍💻 About Me

<img align="right" width="320" src="https://raw.githubusercontent.com/ABSphreak/ABSphreak/master/gifs/Coding.gif"/>

I'm **Youssef Yasser**, a Computer Science student and **Backend-First Full Stack Developer**.

I enjoy building applications from the inside out — designing APIs, database structures, authentication flows, business logic and backend architecture, then connecting everything to a modern frontend.

My main stack revolves around:

`Node.js` · `Express.js` · `TypeScript` · `React` · `Next.js`

with:

`PostgreSQL` · `MySQL` · `Redis` · `MongoDB` · `Docker`

I'm especially interested in **backend engineering, database optimization, scalable APIs, system design and AI-powered applications**.

* 🔐 Authentication & authorization
* 🧩 REST API architecture
* ⚡ Redis integration
* 🌐 Arabic / RTL experience
* 🏗️ Full-stack architecture

## 💰 WealthWise AI

<div align="center">

<img src="https://img.shields.io/badge/AI%20Fintech-Smart%20Wallet-F59E0B?style=for-the-badge"/>
<img src="https://img.shields.io/badge/Next.js-000000?style=for-the-badge&logo=next.js&logoColor=white"/>
<img src="https://img.shields.io/badge/Express.js-111827?style=for-the-badge&logo=express"/>
<img src="https://img.shields.io/badge/PostgreSQL-31648C?style=for-the-badge&logo=postgresql&logoColor=white"/>
<img src="https://img.shields.io/badge/Redis-DC2626?style=for-the-badge&logo=redis&logoColor=white"/>

<br/><br/>

<a href="https://wallet-wep-react.vercel.app/">
<img src="https://img.shields.io/badge/▶%20LIVE%20DEMO-22C55E?style=for-the-badge&labelColor=111827"/>
</a>

</div>

**WealthWise AI** is an AI-powered financial wallet that combines traditional transaction management with natural-language interaction.

A user can enter or speak something like:

> `300 جنيه فراخ و150 عصير`

and the system can turn that input into structured financial transactions.

### 🔥 Highlights

* 💰 Digital wallet experience
* 🤖 Gemini AI integration
* 🗣️ Natural-language transaction parsing
* 🎙️ Voice-based input
* 🧠 AI-assisted categorization
* 🔐 Secure backend workflows
* ⚡ Redis
* 🗄️ PostgreSQL
* 🧩 Full-stack architecture
* 🔒 ACID-aware financial operations
