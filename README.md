I'm **Youssef Yasser**, a Computer Science student and **Backend-First Full Stack Developer**.

I like building complete applications from the backend outward:

```text
💡 IDEA
   ↓
🏗️ ARCHITECTURE
   ↓
🔐 AUTHENTICATION
   ↓
🔌 APIs
   ↓
🗄️ DATABASE
   ↓
⚡ REDIS / BACKGROUND JOBS
   ↓
🤖 AI / INTEGRATIONS
   ↓
🎨 FRONTEND
   ↓
🚀 DEPLOYMENT
```

I enjoy working mainly with **Node.js, Express.js and TypeScript**, while building full-stack products using React / Next.js and databases such as PostgreSQL, MySQL and MongoDB.

**أكلي** هو منصة Food Delivery كاملة مبنية حول دورة الطلب من العميل إلى المطعم.

المشروع فيه حاجات backend حقيقية بدل ما يكون مجرد `products + cart + checkout`.

من أهم الحاجات اللي اشتغلت عليها:

```text
👤 Customer
   ↓
🍔 Restaurant
   ↓
🛒 Cart
   ↓
📦 Order
   ↓
📍 Location
   ↓
⚡ Real-Time Updates
```

وفي الـbackend استخدمت **JWT + HTTP-only cookies**، بالإضافة إلى **Socket.IO** للـreal-time functionality و**MySQL spatial/geospatial capabilities** للتعامل مع البيانات المرتبطة بالموقع والمسافات.

**WealthWise AI** هو Smart Wallet بيجمع بين الـfinancial tracking والـAI.

الفكرة الأساسية إن المستخدم يقدر يتعامل مع بياناته المالية بطريقة طبيعية بدل ما يدخل كل transaction يدويًا بالشكل التقليدي.

مثال:

```text
🗣️ "300 جنيه فراخ و150 جنيه عصير"

             ↓

           🤖 AI

             ↓

┌──────────────────────────┐
│ 🍗 Food       300 EGP    │
│ 🥤 Drinks     150 EGP    │
└──────────────────────────┘

             ↓

        💰 WALLET
```

المشروع يستخدم **Google Gemini** لفهم الـnatural language وتحويله إلى structured financial data، مع backend لإدارة العمليات المالية وRedis والخدمات المرتبطة بها.
