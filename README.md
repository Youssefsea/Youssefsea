## 👨‍💻 About Me

<img align="right" width="330" src="https://raw.githubusercontent.com/ABSphreak/ABSphreak/master/gifs/Coding.gif"/>

I'm **Youssef Yasser**, a Computer Science student and **Backend-First Full Stack Developer** who enjoys turning ideas into complete, production-style applications.

My main focus is building the part users don't always see:

**APIs → Authentication → Databases → Business Logic → Caching → Background Jobs → Integrations → Deployment**

I enjoy working across the stack, but I naturally gravitate toward **backend engineering, API design, databases, system architecture, and scalable application logic**.

### ⚡ What I Like Building

* 🧩 REST APIs & backend services
* 🔐 Authentication & authorization systems
* 🗄️ PostgreSQL / MySQL / MongoDB applications
* ⚡ Redis caching & background processing
* 🐳 Dockerized applications
* 🤖 AI-powered products & integrations
* 🌐 Full-stack applications with React / Next.js
* 🏗️ Systems that solve actual problems instead of just being demo CRUD apps

## 🍔 أكلي — Food Delivery Platform

<a href="https://portfolio-snowy-five-98.vercel.app/">
<img src="https://img.shields.io/badge/🚀%20VIEW%20PROJECT-059669?style=for-the-badge"/>
</a>

### 🧠 What is it?

**أكلي** is a food-delivery platform designed around a real-world ordering workflow.

The system connects users, restaurants, orders and delivery-related functionality into one full-stack application.

### ⚙️ Built With

`Next.js` `Node.js` `Express.js` `MySQL` `Socket.IO` `Leaflet`

### 💥 What I Focused On

* 🔐 JWT authentication
* 🍕 Restaurant & food management
* 🛒 Cart and ordering workflow
* 📍 Location-based functionality
* 🗺️ Geospatial database queries
* ⚡ Real-time communication with Socket.IO
* 🗄️ MySQL spatial indexes
* 🌍 Arabic / RTL interface

### 🔥 Backend Highlight

One of the interesting parts of this project was using **MySQL geospatial functionality and spatial indexing** for location-aware operations instead of treating location as just a normal string.

## 🤖 Backend Bridge AI

### 🧠 What is it?

**Backend Bridge AI** is a backend-focused platform that connects API-related workflows with AI-powered processing.

The system explores how APIs can be parsed, normalized and processed through backend services and AI components instead of treating every integration as a completely manual task.

### ⚙️ Built With

`Node.js` `Express.js` `TypeScript` `MongoDB` `Mongoose` `Redis` `BullMQ` `Python` `Google Gemini`

### 💥 What I Focused On

* 🔌 API processing & normalization
* 🤖 AI-powered backend workflows
* ⚡ Redis
* 🔄 BullMQ background jobs
* 🐍 Python microservice integration
* 🗄️ MongoDB / Mongoose
* 🧩 Service-to-service communication
* 🏗️ Backend architecture
